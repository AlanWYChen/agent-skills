# Web Product Completeness

Check for applicable production surfaces beyond the main page:

- header and navigation
- mobile navigation
- footer
- legal links
- settings
- account lifecycle
- help/support
- empty states
- destructive-action confirmation
- search/filter/sort/pagination
- notifications
- billing/subscription management
- organization/team management
- file upload lifecycle
- admin/support surfaces where relevant
- 404/403/500 pages
- offline/maintenance experiences where applicable

Do not ship placeholder links, fake testimonials, fake metrics, or dead controls.
