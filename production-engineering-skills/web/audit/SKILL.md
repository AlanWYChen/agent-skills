# Web Production Audit

Audit:
- product completeness
- UX states
- forms
- authentication
- authorization
- privacy/consent
- accessibility
- security
- SEO
- performance
- observability
- testing
- GitHub Actions CI/CD
- deployment configuration

Repository sweep:
- TODO
- FIXME
- debugger
- console.log
- localhost
- example.com
- lorem ipsum
- href="#"
- mock data
- hard-coded credentials
- public secrets

Classify findings:
- Critical
- High
- Medium
- Low

For each:
- location
- issue
- impact
- recommended fix

Do not call the app production-ready while Critical findings remain.
