# Backend API Design

Consider:
- stable resource modeling
- versioning policy
- authentication
- authorization
- runtime validation
- consistent error schema
- pagination
- filtering
- sorting
- search
- idempotency
- request IDs
- timeouts
- cancellation where supported
- cache semantics
- rate limits
- OpenAPI/GraphQL schema documentation
- deprecation strategy
- backward compatibility
