# Mobile Performance

Track:
- startup time
- time to interactive
- dropped frames/jank
- memory
- battery
- network usage
- disk usage
- crash-free sessions

Consider:
- lazy initialization
- image resizing/caching
- list virtualization
- avoiding work on main/UI thread
- background work limits
- offline caching
- pagination
- efficient serialization
- minimizing unnecessary bridge/native-module calls in hybrid stacks
